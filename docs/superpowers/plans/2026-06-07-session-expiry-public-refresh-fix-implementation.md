# 2026-06-07 会话过期循环跳转 + 前台返回不刷新修复计划

## 目标
- 修复后台返回前台后文章列表不刷新的问题。
- 修复登录态过期后首页与自动登录反复跳转的问题。
- 过期时清理前后端全部旧登录态（localStorage + cookies）。

## 任务拆分
- [x] Task 1: 将前台首页改为动态渲染，避免返回后复用旧缓存。
- [x] Task 2: 登录态刷新失败时，客户端触发服务端注销并清理本地会话。
- [x] Task 3: 统一完善注销/刷新失败时的 cookie 清理范围（ADMIN + PERSONAL + LEGACY）。
- [x] Task 4: 登录页自动登录策略收敛，缺失或已过期本地会话不再触发自动刷新。
- [x] Task 5: 运行质量验证并记录证据（lint/typecheck，必要时补充 e2e）。

## 验收标准
- 进入首页时可以获取最新已发布文章列表，不出现后台变更后前台仍是旧列表的情况。
- 登录态过期后进入后台登录页，不会在首页与自动登录过程间循环跳转。
- 刷新令牌失效后，浏览器内残留的认证 cookie 会被服务端清空。
