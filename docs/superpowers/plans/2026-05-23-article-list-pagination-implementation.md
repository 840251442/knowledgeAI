# 2026-05-23 Article List Pagination Implementation Plan

## 目标
- 为公开文章列表增加分页能力，支持稳定的页间跳转与 URL 同步。
- 在不新增后端接口、不修改数据库 schema 的前提下完成交付。
- 保证关键 E2E 用例通过，避免对现有浏览链路造成回归。

## 约束
- 不改数据库 schema。
- 不新增后端接口。
- 仅修改现有文章列表页与相关测试。
- 目标分支：`dev`。

## 范围
- 包含：文章列表分页交互、URL `page` 参数同步、边界态处理、相关 E2E 更新。
- 不包含：管理端分页改造、搜索页分页重构、缓存架构调整、鉴权逻辑变更。

## 风险与应对
- 风险：现有接口缺少总量信息，导致总页数计算不稳定。
  - 应对：优先复用现有返回字段；若不足，启用前端分页分支并限制 UI 承诺。
- 风险：URL 参数与组件状态不同步导致显示页与数据页不一致。
  - 应对：以 URL 作为单一数据源，翻页统一走参数更新流程。
- 风险：E2E 对固定列表顺序依赖较强，分页后断言脆弱。
  - 应对：改为断言页码与列表变化特征，避免强耦合具体顺序。
