# Work Progress 记录规范

本目录用于记录复杂任务执行过程中的过程性进展。

## 目录约定

- 每个复杂任务创建一个子目录：`docs/superpowers/work-progress/<任务标识>/`
- 子目录中必须包含：`progress.md`

示例：
- `docs/superpowers/work-progress/2026-05-23-search-refactor/progress.md`

## 更新时机

- 计划文档生成后初始化 progress.md
- 每个关键阶段完成后更新（需求、计划、执行、验收）
- 出现阻塞或风险变化时立即更新
- 合并前补齐最终验证结果与结论

## 最小字段

- 目标
- 当前阶段
- 已完成项
- 进行中
- 阻塞项
- 下一步
- 验证证据（命令与结果）
